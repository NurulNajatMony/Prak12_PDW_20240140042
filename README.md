# Prak12_PDW_[NIM]

> Praktikum 12 - Pemrograman dan Desain Web  
> Universitas Muhammadiyah Yogyakarta

## 📋 Deskripsi

Aplikasi **Pendaftaran Peminatan** berbasis React yang memungkinkan mahasiswa mendaftarkan pilihan peminatan bidang studi (Programming, Desain, Jaringan, Data). Dibuat menggunakan React + Vite + Tailwind CSS dengan tema galaxy/space yang interaktif.

## 🚀 Fitur

- Form pendaftaran lengkap (Nama, NIM, Peminatan, Angkatan, Tanggal Lahir, Alamat)
- Validasi input sebelum submit
- Tampilan hasil registrasi setelah submit
- Animasi bintang, nebula, planet, dan roket
- Responsive design untuk mobile dan desktop

## 🛠️ Tech Stack

- **React 18** – UI Library
- **Vite** – Build Tool
- **Tailwind CSS** – Utility-first CSS Framework

```bash

# 2. Install dependencies

# 3. Jalankan development server

# 4. Build untuk production

```
